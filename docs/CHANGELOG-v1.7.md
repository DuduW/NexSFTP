# v1.7 变更记录（2026-10-13）

## 新增
- one-click.sh --file-root 参数：安装时自定义用户数据根目录（默认 /srv/sftp），含三重安全校验（绝对路径/禁..与空格/禁系统关键目录），贯通 systemd 沙箱与摘要横幅
- 分配项目管理员弹窗：卡片式人员选择（勾选高亮/当前徽标/备注/最后登录）

## 修复
- 管理员列表角色徽标三分支：project_admin 显示橙色「项目管理员」（原落入灰色「管理员」）
- 审计日志对项目管理员三层禁用：前端隐藏导航 + 页面直达显示「日志已禁用」空态（不闪加载中）+ API 403

## UI 统一（弹窗全套对齐账号弹窗版式）
- 新建/编辑项目：＋/✏️ 标题式 + row 双列 + ⚡标识自动生成 + 实时校验 + 按钮联动禁用
- 停用项目：原生 confirm 升级红色危险确认弹窗（后果清单：N 账号冻结/在线强断/可恢复）；启用直通不弹窗

- 项目列表停用行 opacity 弱化；分配保存中状态与结果 toast
