# NexSFTP 安装使用说明

> 版本：v1.4（2026-10-12）｜ 适用：Rocky Linux 9（RHEL 系亦可参考）｜ 数据库：MySQL 8（可回退 SQLite）

## 一、一键部署（推荐）

### 1.1 前置条件

- Rocky Linux 9 x64，root 权限
- 可访问外网（dnf 源 + pip 阿里云镜像）
- 端口空闲：SFTP 2022、管理面 80（可改）

### 1.2 部署步骤

```bash
# 解压部署包
unzip sftpserver-v1.4-deploy-20261012.zip -d sftpserver
cd sftpserver/deploy

# 一键部署（全自动：MySQL 安装 → 建库授权 → venv → systemd → 防火墙 → 健康验证）
sudo bash one-click.sh
```

### 1.3 常用选项

| 参数 | 默认 | 说明 |
|------|------|------|
| `--db-pass PWD` | 随机生成 20 位 | MySQL 应用账户密码（打印在部署完成横幅） |
| `--db-name` | sftpserver | 库名 |
| `--db-user` | sftpserver | 应用账户名 |
| `--admin-port` | 80 | 管理面端口（<1024 自动加 AmbientCapabilities，非 root 绑定） |
| `--sftp-port` | 2022 | SFTP 传输面端口 |
| `--skip-mysql` | - | 已有自管 MySQL 时跳过安装（仍自动建库授权） |
| `--mirror URL` | 阿里云 | pip 镜像 |

脚本**幂等**：重复执行安全，不破坏已有数据。

### 1.4 部署结果

```
/opt/sftpserver          代码 + venv
/var/lib/sftpserver      数据（host key / secret）
/srv/sftp                用户文件根
/etc/sftpserver.env      DB 连接（600 权限）
systemd: sftpserver.service（enable，开机自启）
```

## 二、访问入口与初始账号

| 入口 | 地址 | 凭证 |
|------|------|------|
| 管理后台 | `http://<IP>/admin` | admin / admin1234 **⚠️ 首登立即修改** |
| Web 文件访问 | `http://<IP>/web/login` | SFTP 用户账号 |
| SFTP | `sftp -P 2022 <user>@<IP>` | SFTP 用户账号 |
| API 文档 | `http://<IP>/api/docs` | - |

> 端口改过则相应替换；管理面当前为 HTTP，生产建议 Nginx + 内网 CA 反代上 HTTPS。

## 三、日常使用

### 3.1 管理后台

- **仪表盘**：账号总览、在线会话、7 日上传/下载趋势、磁盘 TOP5
- **SFTP账号管理**：创建/编辑用户（四权限 R/W/D/M、空间/文件数/单文件配额、上下行限速、并发数、有效期、Web 开关、备注）；加密路径一键复制/轮换；重置密码；删除（需输入用户名二次确认，60 秒限删一个）
- **后台账号管理**（仅 super_admin）：管理员增删改/角色分配/重置密码；普通 admin 仅日常管理，不能管理管理员
- **会话监控**：在线 SFTP 会话实时列表，可强制断开
- **审计日志**：全操作留痕（SFTP/Web/管理三源），按用户/动作过滤，一键导出 CSV（含传输字节数）
- **用户 Web 访问**：全员加密路径总览与轮换

### 3.2 用户 Web 文件访问

登录 `/web/login` → 自动进入本人加密路径 → 列表/上传（多文件）/下载/改名/删除（按权限显示按钮）→ 支持子目录与面包屑导航。

### 3.3 SFTP 客户端

FileZilla / WinSCP / OpenSSH `sftp` 均可：协议 SFTP，端口 2022，虚拟账号密码认证。权限、配额、限速与 Web 面完全一致。

## 四、账号与权限模型

| 组 | 表 | 可登录 | 不可登录 |
|------|------|------|------|
| SFTP 用户 | sftp_users | SFTP :2022、Web 文件 | 管理后台 |
| 后台管理员 admin | admins | 管理后台 | SFTP、Web 文件 |
| 超级管理员 super_admin | admins | 管理后台 + 用户组管理 | SFTP、Web 文件 |

四权限独立组合：读（列表/下载）、写（上传/建目录）、删、改名（M）。

## 五、运维手册

```bash
systemctl status|restart|stop sftpserver     # 服务
journalctl -u sftpserver -f                  # 日志
mysql sftpserver                             # 数据（admins/sftp_users/audit_logs）
```

- **配额对账**：每 5 分钟后台线程磁盘实扫自动校正用量
- **备份**：`mysqldump sftpserver` + `/srv/sftp` 目录同步即可全量恢复
- **升级**：新版 zip 解压覆盖 `/opt/sftpserver`（保留 venv/data）→ `systemctl restart sftpserver`；数据库结构变更由启动时自动迁移完成
- **改配置**：`/etc/sftpserver.env`（DB 连接）→ `systemctl restart`

## 六、常见问题

| 现象 | 处理 |
|------|------|
| 管理页 502/连不上 | `systemctl status sftpserver`；端口被占改 `--admin-port` |
| 服务起来但回退 SQLite | 检查 `/etc/sftpserver.env` 是否存在且 URL 正确（密码特殊字符须 URL 编码） |
| SFTP 能连不能读写列目录 | 检查用户四权限与服务日志；v1.3 已修 Linux 读 bug，老版本请升级 |
| 用户 Web 登录 401 | 确认账号 web_enabled 开、enabled 开、未过期、密码正确 |
| 加密路径 404 | 属安全设计：必须先登录且 token 属主=会话用户；轮换后旧路径立即失效 |

## 七、安全建议（生产）

1. 修改 admin 初始密码；按人建独立管理员账号（super_admin 保留 1-2 人）
2. 管理面套 HTTPS（Nginx + 内网 CA）
3. `/srv/sftp` 迁移独立 XFS 数据卷并启用 pquota（OS 级硬配额）
4. 防火墙限制 80 端口来源网段（rich rule）
5. 定期导出审计 CSV 归档（页面一键）
